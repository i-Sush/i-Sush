## AI / Machine Learning

### <img src="../assets/icons/data.svg" width="24" alt="Data icon"> [Data-Mining-Case-Studies](https://github.com/i-Sush/Data-Mining-Case-Studies)

**Overview.** A collection of basic data mining and machine learning case studies in Python on real-world datasets, covering classification, feature scaling and dimensionality reduction. It is part of my academic learning and practice.

**What it demonstrates.** How preprocessing choices (scaling, PCA, cleaning) interact with different models, evaluated with accuracy and MSE.

**Case studies**

| Case study | Task | Techniques and algorithm | Dataset |
| :-- | :-- | :-- | :-- |
| [Insurance Claim](https://github.com/i-Sush/Data-Mining-Case-Studies/tree/main/Insurance_Claim) | Classification: will a claim be approved? | Decision Tree | Insurance Claims Dataset |
| [Wine Quality](https://github.com/i-Sush/Data-Mining-Case-Studies/tree/main/Wine_Quality) | Classification: predict quality from chemical properties | StandardScaler, PCA, Random Forest / Logistic Regression | Wine Quality (UCI) |
| [Flight Delay Prediction](https://github.com/i-Sush/Data-Mining-Case-Studies/tree/main/End-to-End_Preprocessing_Flight_Delay_Prediction) | Classification: will a flight be delayed? | Data cleaning, scaling, PCA, Decision Tree | Flight Delay (USDOT / Kaggle) |
| [Energy Consumption](https://github.com/i-Sush/Data-Mining-Case-Studies/tree/main/Feature_Scaling_In_Energy_Consumption_Data) | Regression: effect of scaling on forecasting | StandardScaler, Linear Regression | Household Electric Power Consumption (UCI) |

The repository also includes a [Viva-Questions.md](https://github.com/i-Sush/Data-Mining-Case-Studies/blob/main/Viva-Questions.md) revision file.

**Technologies:** Python · Pandas · NumPy · Scikit-learn · Jupyter Notebook

**Repository:** [github.com/i-Sush/Data-Mining-Case-Studies](https://github.com/i-Sush/Data-Mining-Case-Studies)
