## How Streaks Are Counted

- Streaks come from GitHub's own contribution calendar: commits to a repository's default branch, opened pull requests and issues, and code reviews all count.
- Private-repository activity appears only if **Contribution settings → Private contributions** is switched on for my profile. These cards never read private repositories directly.
- A day with no contribution resets the current streak, but never the longest streak.
